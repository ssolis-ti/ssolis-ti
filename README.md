### 🚀 Proyectos Destacados / Featured Projects

#### 🇨🇱 [Compra Ágil MCP Server](https://github.com/ssolis-ti/compra-agil-mcp)
* **🇪🇸 Qué hace:** Servidor MCP en TypeScript que envuelve la API de Mercado Público de Chile. Permite a agentes de IA buscar, auditar y monitorear compras estatales, incluyendo alertas automáticas en segundo plano para procesos con 0 oferentes.
* **🇬🇧 What it does:** TypeScript-based MCP server wrapping Chile's Mercado Público API. It enables AI agents to search, audit, and monitor public procurement, featuring background alerts for processes with 0 active bids.
* **Tech:** `TypeScript` · `Node.js` · `MCP (Model Context Protocol)` · `Mercado Público API`

---

#### 🤝 [Two MCP Party](https://github.com/ssolis-ti/two-mcp-party)
* **🇪🇸 Qué hace:** Conecta dos o más agentes de IA a través de red local (LAN) para colaboración en equipo, chat, transferencia de archivos y espacios de trabajo compartidos.
* **🇬🇧 What it does:** Connect two or more AI agents over LAN for teamwork, chat, file transfer, and workspace sharing.
* **Tech:** `MCP (Model Context Protocol)` · `LAN` · `Multi-Agent`

---

#### 🤖 [CrewAI MCP HeadQuarter](https://github.com/ssolis-ti/crewai-mcp-hq)
* **🇪🇸 Qué hace:** Servidor MCP diseñado para desplegar y gestionar equipos de agentes (crews) de CrewAI, permitiendo la integración nativa de múltiples agentes con tu asistente de IA principal.
* **🇬🇧 What it does:** MCP server designed to deploy and manage CrewAI agent teams (crews), enabling native multi-agent integration with your main AI assistant.
* **Tech:** `Python` · `CrewAI` · `MCP (Model Context Protocol)`

---

#### ✍️ [WordPress AI Content System MCP](https://github.com/ssolis-ti/wordpress_content_ai_mcp)
* **🇪🇸 Qué hace:** Servidor MCP en Python que automatiza el ciclo de vida del contenido en WordPress. Integra investigación de temas, redacción multimodelo (Gemini, OpenAI, Claude, Ollama), auditorías SEO en tiempo real y enlazado interno automático.
* **🇬🇧 What it does:** Python-based MCP server that automates the WordPress content lifecycle. It features topic research, multi-model AI writing (Gemini, OpenAI, Claude, Ollama), real-time SEO audits, and automated internal linking.
* **Tech:** `Python` · `MCP (Model Context Protocol)` · `WordPress` · `LiteLLM` · `SEO`

#### 📰 [RSS AI Rewriter](https://github.com/ssolis-ti/rss-rewriter-ai)
* **🇪🇸 Qué hace:** Plugin de WordPress que lee fuentes RSS, reescribe los artículos usando IA, genera imágenes automáticas y optimiza el contenido para SEO antes de publicar.
